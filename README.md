## Features

- ✨ CRUD completo de pensamentos (criar, listar, editar, excluir)
- 🚀 API REST Express com Mongoose e autenticação JWT
- ⚡ Componentes Angular com services e HttpClient
- 🎯 Layout com cabeçalho e rodapé customizados
- 🔧 Projeto fullstack frontend + backend separados

## Stack

- **Frontend:** Angular 14
- **Backend:** Node.js, Express, JWT, jwt-decode
- **Dados:** MongoDB
- **Outros:** TypeScript
